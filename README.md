# Сайт-портфолио

Статический сайт без сборки, две страницы в стиле Apple glass:

- `index.html` — продающий лендинг: боли, реальный кейс, услуги, условия, как начать (14 дней бесплатно и цена кейса), этапы, FAQ, контакты. Цен на сайте нет намеренно: их называем после консультации;
- `projects.html` — проекты в виде инфографики: схемы, графики, цифры из демо.

Общие `styles.css` и `script.js`, медиа в `assets/`.

## Перед публикацией

Все места, где нужны ваши данные, помечены комментарием `TODO` в HTML. Текстовые заглушки ещё и обведены оранжевым пунктиром на странице (атрибут `data-todo`): заполнив заглушку, уберите у элемента `data-todo`. Проверить, что ничего не осталось:

```bash
grep -n "TODO\|data-todo" index.html projects.html
```

В `index.html`:

- **Контакты:** заполнены — Telegram @Adil_Zakarin, WhatsApp и телефон +7 705 448 89 10;
- **Интеграции:** уберите то, за что не берётесь; добавьте 1С и Kaspi, если работаете с ними;
- **Живые демо:** когда задеплоите, добавьте ссылки «Попробовать» в карточки услуг.

## Посмотреть локально

```bash
python3 -m http.server 4321
```

Затем открыть http://localhost:4321.

## Публикация

Подойдёт любой статический хостинг: перетащить папку `site` в Netlify Drop (app.netlify.com/drop) или задеплоить через Vercel / GitHub Pages.
